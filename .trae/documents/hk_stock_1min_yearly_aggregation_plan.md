# 港股1分钟数据按年汇总实施计划

## 任务概述
参考 `1分钟按年汇总代码.py`，对 `/media/sky/Data/stock/港股_分时数据/1分钟_按月归档` 目录下的数据进行按年汇总。

## 数据结构分析

### 源数据结构
- **源目录**: `/media/sky/Data/stock/港股_分时数据/1分钟_按月归档`
- **目录结构**: 按月分目录（如 `2025-02`, `2025-03`, ..., `2026-03`）
- **文件命名**: `YYYYMMDD_1min.zip`（如 `20250203_1min.zip`）
- **ZIP内容**: 每个ZIP包含多个股票的CSV文件（如 `00001.HK.csv`）
- **CSV格式**: 包含"时间"列，需要按年份分组

### 目标输出结构
- **临时目录**: `/media/sky/Data/stock/港股_分时数据/1分钟_按年汇总_tmp`
- **最终目录**: `/media/sky/Data/stock/港股_分时数据/1分钟_按年汇总`
- **输出格式**: 按年份分目录，每个股票生成 `{股票代码}_{年份}.csv`，最终打包成 `{年份}_1min.zip`

## 实施步骤

### 步骤1: 创建新的Python脚本
- **文件路径**: `/home/sky/project/daily_stock_analysis/港股1分钟按年汇总.py`
- **功能**: 参考原脚本，适配港股数据路径和文件命名

### 步骤2: 配置参数调整
修改以下配置项：
```python
SOURCE_DIR = "/media/sky/Data/stock/港股_分时数据/1分钟_按月归档"
OUTPUT_DIR = "/media/sky/Data/stock/港股_分时数据/1分钟_按年汇总_tmp"
FINAL_DIR = "/media/sky/Data/stock/港股_分时数据/1分钟_按年汇总"
```

保持以下配置不变：
- `FILENAME_PATTERN = re.compile(r"(\d{8})_1min\.zip")`
- `CHUNK_SIZE = 50_000`
- `ENCODING = "utf-8-sig"`
- `CLEAN_TMP = True`

### 步骤3: 核心功能实现
脚本需要包含以下函数：

1. **collect_zip_files()**: 收集所有ZIP文件
   - 遍历源目录
   - 匹配文件名模式 `YYYYMMDD_1min.zip`
   - 返回ZIP文件路径列表

2. **process_zip(zip_path)**: 处理单个ZIP文件
   - 打开ZIP文件
   - 遍历其中的CSV文件（股票代码.csv）
   - 使用chunk方式读取CSV（避免内存溢出）
   - 从"时间"列提取年份
   - 按年份分组数据
   - 追加写入到 `{OUTPUT_DIR}/{年份}/{股票代码}_{年份}.csv`

3. **pack_by_year()**: 按年打包
   - 遍历临时目录中的年份目录
   - 将每个年份目录下的所有CSV文件打包成一个ZIP
   - 输出到 `{FINAL_DIR}/{年份}_1min.zip`

4. **main()**: 主函数
   - 收集所有ZIP文件
   - 逐个处理ZIP文件
   - 执行按年打包
   - 清理临时目录

### 步骤4: 日志和进度显示
- 使用logging记录处理过程
- 使用tqdm显示进度条（处理ZIP、处理CSV文件、年度打包）

### 步骤5: 测试验证
运行脚本并验证：
1. 临时目录是否正确生成
2. CSV文件是否按年份正确分组
3. 最终ZIP文件是否正确打包
4. 数据完整性检查（抽样验证）

## 关键注意事项

1. **内存管理**: 使用chunk方式读取CSV，避免一次性加载大文件
2. **文件编码**: 使用 `utf-8-sig` 编码处理CSV文件
3. **错误处理**: 添加异常处理，防止单个文件失败导致整个流程中断
4. **进度追踪**: 使用tqdm显示详细进度，方便监控处理状态
5. **临时文件清理**: 处理完成后清理临时目录（可通过配置控制）
